Principle

읽기 전용 + 승인 게이트

✅ AI가 하는 것
  • CloudWatch 로그 읽기
  • 상관관계 분석
  • 진단 리포트 생성

  • IAM 변경

Lessons Learned

설계 교훈

1. Read-only 경계 = 공포 제거
최악 = 쓸데없는 API 호출 비용
쓰기는 물리적으로 불가능
2. 승인 = conditional write
별도 오케스트레이터 없이
DynamoDB 낙관적 락으로 원자적 전이
3. Socket Mode = 포트 0
가장 간과되는 보안 결정
인바운드 엔드포인트 자체가 없음
4. 비용 투명성 = 신뢰
매 실행마다 토큰/비용/도구 호출 수
footer에 노출 → "얼마 쓰는지 안다"
